# Zerks-X6: макет на екрана

Неподвижни кадри от бъдещия екран на играта в размер на iPhone: 3D сцена на колонията (three.js) и интерфейсът отгоре. Това е макет за визията, не кодът на играта. С какво ще се прави самото приложение още не е решено.

## Какво е решено в макета

- Камерата е само отгоре, героят не се управлява, всичко става с натискане.
- Интерфейсът е минимален: иконки, които подсказват, а менютата се отварят при натискане.
- Сградите стоят в парцели по мрежа от клетки по 3 м. Всяка сграда заема толкова клетки, колкото ѝ трябват: малки 2×2, средни 3×2, големи 3×3, Ковчегът 7×3.
- ЕХО е малкото роботче водач.

## Как се пуска

Нужни са Node.js, Python 3 и Playwright с Chromium.

```bash
cd mockup
npm install
npm run assets
npm run serve
```

В друг терминал:

```bash
cd mockup
npm run shots
```

Кадрите излизат в `out/`. Едно състояние се отваря и в браузъра: `http://127.0.0.1:8777/index.html#early` (още `#early-zoom`, `#early-panel`, `#early-build`, `#early-place`, `#late`, `#late-zoom`).

## Файлове

| Файл | Какво прави |
| --- | --- |
| `index.html` | Страницата и интерфейсът: пръстенът за атмосферата, нивото, ресурсите, иконките на картата, докът, панелът на сградата |
| `src/main.js` | Сцената за всяко състояние: подредбата на парцелите, камерата, светлината, околната сянка и сиянието |
| `src/models.js` | Моите детайлни модели: Ковчегът, сондата, атмосферният процесор, кулите, корабът в скелето и др. |
| `src/world.js` | Каньонът, терените, скалите, дърветата, пътищата |
| `src/textures.js` | Текстурите, генерирани с код: панели с фуги, метал, соларни клетки, фасади |
| `fetch-assets.sh` | Тегли моделите на Kenney и текстурите от Poly Haven в `models/` и `ph/` |
| `shot.js` | Снима състоянията в `out/` |

## Източници и лицензи

- **Ковчегът и карбоновата сонда:** гладките модели от CellCog в `art/3d` (02.11.2026); `fetch-assets.sh` ги копира в `models/`. Старите модели, построени с код, са още в `src/models.js`.
- **Kenney Space Kit** (kenney.nl): модели на хангари, куполи, чинии, генератори, роувър, астронавт, ракета, скали. Лиценз CC0. Взети са от npm копието `@anabis/kenney-space-kit-mirror`.
- **Poly Haven** (polyhaven.com): сканирани текстури (почва, трева, бетон, асфалт, чакъл, метал) и небето `kloofendal_48d_partly_cloudy_puresky`. Лиценз CC0.
- **Exo 2** (Google Fonts): шрифтът на интерфейса. Лиценз SIL Open Font License 1.1.
- **three.js**: лиценз MIT.
