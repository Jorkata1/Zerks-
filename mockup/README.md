# Zerks-X6: макет на екрана

Неподвижни кадри от бъдещия екран на играта в размер на iPhone: 3D сцена на колонията (three.js) и интерфейсът отгоре. Това е макет за визията, не кодът на играта. Самата игра ще се прави с Unity 6 (Саламен, 13.11.2026, docs/unity-plan.md).

## Какво е решено в макета

- Камерата е под ъгъл като в градостроителна игра (решено на 04.11.2026; по-старите кадри са отгоре), героят не се управлява, всичко става с натискане.
- Интерфейсът е минимален: иконки, които подсказват, а менютата се отварят при натискане.
- Сградите стоят в парцели по мрежа от клетки по 3 м. Всяка сграда заема толкова клетки, колкото ѝ трябват: малки 2×2, средни 3×2, големи 3×3. На картата на ниво 10 всяка сграда е в свой парцел от 12 м, а Ковчегът е на парцел 2×2 в центъра, 28 м без улиците между тях (Жоро, 06.11.2026).
- ЕХО е малкото роботче водач.

## Как се пуска

Нужни са Node.js, Python 3 и Playwright с Chromium.

```bash
cd mockup
npm install
npm run assets
npm run serve
```

В друг терминал:

```bash
cd mockup
npm run shots
```

Кадрите излизат в `out/`. Новата приятелска визия е в `cartoon.html` (`src/cartoon.js`), състояния `#lvl1` и `#lvl3`: `node shot.js 3 lvl1,lvl3 cartoon.html`. Картата е в `map.html` (`src/map.js`): колонията на ниво 10 само със сградите, които `docs/levels.md` има до ниво 10, денем `#lvl10` и нощем `#lvl10-night` (`node shot.js 3 lvl10,lvl10-night map.html`). С `#lvl10-ark-a` и `#lvl10-ark-b` (и с `-night`) на мястото на Ковчега стои една от двете първи идеи за него (`art/3d/buildings/ideas/ark-a.glb`, `ark-b.glb`, 06.11.2026); листът за сравнение е `catalog.html#set=ark` (`node shot-catalog.js ark`). Ползваме само нея (Жоро, 06.11.2026); старите примерни карти при 20%, 50% и 85% (`#atm…`, `#kk…`), кадрите им и клипът са махнати. Кадрите отблизо се правят с `window.__aim(ширина в метри, x, z)`: лявата половина `46, -6.5, 10.5`, дясната `46, 10.5, -6.5` (и двете с целия Ковчег), домът `20, -16, -32`, Ковчегът `40, -10, -10`. Едно състояние се отваря и в браузъра: `http://127.0.0.1:8777/index.html#early` (още `#early-zoom`, `#early-panel`, `#early-build`, `#early-place`, `#late`, `#late-zoom`).

## Файлове

| Файл | Какво прави |
| --- | --- |
| `index.html` | Страницата и интерфейсът: пръстенът за атмосферата, нивото, ресурсите, иконките на картата, докът, панелът на сградата |
| `src/main.js` | Сцената за всяко състояние: подредбата на парцелите, камерата, светлината, околната сянка и сиянието |
| `src/models.js` | Моите детайлни модели: Ковчегът, сондата, атмосферният процесор, кулите, корабът в скелето и др. |
| `src/world.js` | Каньонът, терените, скалите, дърветата, пътищата |
| `src/map.js` | Картата на ниво 10 с камера под ъгъл: мрежата от улици, сградата във всеки парцел, очертанията на празните парцели, прахът над зоната II |
| `src/colony.js` | Лампите, пейките и саксиите по тротоарите на картата. В него са и старите сгради в стила на Ковчега от махнатата примерна карта (къща, блок, оранжерия и др.), които картата вече не ползва |
| `src/textures.js` | Текстурите, генерирани с код: панели с фуги, метал, соларни клетки, фасади |
| `fetch-assets.sh` | Тегли моделите на Kenney и текстурите от Poly Haven в `models/` и `ph/` |
| `shot.js` | Снима състоянията в `out/` |
| `src/map-ideas.js`, `shot-ideas.js`, `map-ideas.html`, `shot-sheet.js` | Предложенията за картата: всяко се включва отделно с `map.html?ideas=canyon,ground,ice,lines,rover,zone#lvl10` (или `ideas=all`); още `dust` и `rocks`; `canyon0` е първият каньон от блокове, пазен само за сравнение. `node shot-ideas.js` снима всеки изглед без тях и с тях, `node shot-sheet.js map-ideas p1` (`p2`, `p3`) прави трите страници на листа |
| `menus.html` | Менютата: всяко състояние е един екран (`#main`, `#build`, `#place`, `#building`, `#ark`, `#research`, `#colonists`, `#dossier`, `#wake`, `#goals`, `#away`); `node shot.js 3 main,build,… menus.html` |
| `thumbs.html`, `src/thumbs.js`, `shot-thumbs.js` | Картинките за менютата в `ui/thumbs` (WebP на прозрачен фон): всяка сграда от камерата на картата и портрет и цял ръст на всеки човек от `art/3d/characters` |
| `shot-bg.js` | Фоновете на менютата (`ui/bg-*.jpg`, картата без интерфейса) и къде е всяка сграда на тях (`ui/anchors.json`) |
| `shot-map.js` | Снима всички кадри на картата на ниво 10 за `screens/` (цялата, двете половини, домът, Ковчегът, Командирът с ЕХО, колонист; денем и нощем) |
| `catalog.html`, `src/catalog.js`, `shot-catalog.js` | Каталогът на сградите: всеки модел сам в парцел, със светлината и камерата на картата; `node shot-catalog.js` прави `out/catalog.jpg` (за `art/3d/buildings`) и `out/buildings-kk.jpg` (вариантът за телефон) |
| `src/build-seq.js`, `shot-build.js`, `clip-build.js` | Строежът на сграда върху картата на ниво 10 (`map.html#lvl10-build`): `window.__buildAt(t)` показва момента t; `node shot-build.js 2,9,14` прави кадри, `node clip-build.js` прави клипа с ffmpeg |
