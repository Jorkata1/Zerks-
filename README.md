# Zerks-X6

Игра-приложение за телефон (iOS и Android), вертикално, в космически стил. Сега сме в концепцията.

- `docs/levels.md`: логиката на играта по нива; при противоречие с другите документи важи той
- `docs/notes.md`: бележки, задачи, решения, дневник
- `docs/chat-log.md`: хронологията на чата, записва се при всяко качване
- `docs/concept.md`: концепцията на играта като idle оцеляване
- `docs/game-flow.md`, `docs/game-flow-concept.md`: ходът на играта стъпка по стъпка
- `docs/build-sequence.md`: кадърът на строежа с дрона
- `docs/ideas.md`: файлът за идеи; `npm run docx` прави от него `docs/Zerks-X6-ideas.docx`
- `docs/drafts/`: чернови на нови нива за преглед; `docs/example/`: пример за 100 нива, само за идеи
- `docs/handover.md`: предаването на екипа
- `docs/practices.md`, `docs/practices-tools.md`: наученото от кода на предишния проект
- `deck/project/`: презентацията (визията)
- `art/3d/buildings/`: 3D сградите и правилата на стила; `mockup/`: макетът на екрана
- `CLAUDE.md`: правилата за двата чата и командите „обнови чат“ и „актуализирай и качи“
