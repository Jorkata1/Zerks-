# Fonts

Nunito ExtraBold (800) and Black (900), by Vernon Adams, Cyreal and Jacques Le Bailly, under the SIL Open Font License
1.1 (https://openfontlicense.org): the rounded font of the friendly look (mockup/menus.html, a proposal of 14.11.2026).
Converted from the mockup's woff2 files (mockup/fonts, Latin letters only; the text of the game is in English).

Roboto Medium and Bold, by Christian Robertson for Google, under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0). Copied from Unity's com.unity.searcher package for the test version of
the game's interface; now the fallback for the arrows, stars and crosses that the Latin Nunito does not have.
