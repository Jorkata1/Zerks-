# Zerks-X6: кодът на играта

TypeScript, three.js (3D) и Vite; по-късно Capacitor за iOS и Android (решено от Саламен, 13.11.2026; планът е в `docs/code-plan.md`). Текстът в играта е на английски.

## Какво има

| Част | Какво е |
| --- | --- |
| `src/main.ts` | Етап 1: колонията на ниво 10, камерата, тапът, денят и нощта, дронът и роботът, броячът на кадрите |
| `src/view/` | 3D сцената: картата по одобрения макет (`world.ts`), моделите (`models.ts`), камерата (`camera.ts`), допирът (`input.ts`), денят и нощта (`daynight.ts`), какво се движи (`movers.ts`), сливането за по-малко рисувания (`merge.ts`), меките текстури с `softTexture` (`soft.ts`), малките неща в кода (`props.ts`) |
| `src/ui/` | Интерфейсът (HTML и CSS) |
| `src/balance/` | Моделът на числата (баланс 0.1); резултатът е в `docs/balance/` |
| `test/` | Тестовете: баланса, камерата, деня и нощта |
| `tools/` | Подготовката на моделите, снимките и клипът в размер на телефон, страницата за линка, баланса |

## Как се пуска

От тази папка (Node 22):

1. `npm install` (само първия път).
2. `npm run models`: прави моделите за играта от `art/3d/buildings` (квантизирани GLB, без декодер; не се качват в git).
3. `npm run dev`: играта на локален сървър, с отваряне на телефон в същата мрежа.
4. `npm run check`: проверка на типовете, тестовете и build до един HTML файл (`dist/index.html`).
5. `npm run artifact`: страницата за линка (`dist/artifact.html`); публикува се на същия линк (виж CLAUDE.md).
6. `node tools/shots.mjs 1 shots`: снимки в размер на iPhone (390×844), денем, нощем, при избрана сграда и отблизо.
7. `node tools/clip.mjs shots 60`: клип кадър по кадър (полетът на дрона и смрачаването) и лист с кадри.
8. `npm run balance`: моделът на числата; после `python3 ../docs/balance/make-balance-xlsx.py`.

## Настройки в адреса (за проба)

`?t=0.8` фиксира часа (0–1; от 0,6 нататък е нощ), `?day=120` е дължината на деня в секунди, `?at=10` е моментът на дрона и робота, `?still` спира времето, `?dpr=2` е разделителната способност, `?view=40` е колко метра се виждат.

## Какво още не е проверено

- Колко гладко върви на iPhone: в облака няма видеокарта, затова кадрите в секунда тук не значат нищо. Броячът долу вляво показва кадрите, рисуванията и триъгълниците на телефона.
- Защитата на страницата в Claude: моделите са вътре в страницата и се четат без fetch и без WebAssembly, за да минат и при строга защита.
